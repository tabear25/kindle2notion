# Android で使う（APK 版 / PWA 版）

Vercel で配信しているスマホ向けの画面を、Android のアプリとして使う方法は 2 つあります。
どちらも中身は同じ画面（`frontend/`）なので、画面の修正は `main` へのマージ → Vercel の再デプロイで両方に届きます。

| | APK 版（`android/`） | PWA 版（Chrome からインストール） |
| --- | --- | --- |
| ホーム画面ウィジェット | **あり**（「Kindle同期」「手動で追加」の 2 ボタン） | なし（ショートカットのピン留めで代用） |
| アイコン長押しのショートカット | あり（＋「接続先を変更」） | あり |
| 他のアプリの「共有」から追加 | あり（共有先の名前は「ハイライトに追加」） | あり（「ハイライト」） |
| 入れ方 | APK を直接インストール（提供元不明のアプリ） | Chrome の「アプリをインストール」 |
| アプリ本体の更新 | `android/` を変えたときだけ APK を入れ直す | 不要 |

両方入れる必要はありません。ウィジェットを使いたいなら APK 版、手軽さ優先なら PWA 版です。

---

## APK 版

### できること

| 操作 | 動き |
| --- | --- |
| ウィジェットの「Kindle同期」／アイコン長押し →「Kindle同期」 | バックエンドの起動を待って**自動で同期を開始**（待っている間は画面が消えない） |
| ウィジェットの「手動で追加」／アイコン長押し →「手動で追加」 | 紙の本などのハイライト入力画面を開く |
| 他のアプリの「共有」→「ハイライトに追加」 | 共有した文章が入力済みの状態で手動追加画面が開く |
| アイコン長押し →「接続先を変更」 | 開く画面の URL（Vercel）を変える |
| 同期中・2 段階認証待ちのときにアプリを開く | 実行中の同期に自動で再接続（進捗と 2FA 入力欄を再表示） |

### インストール（1 回だけ）

1. 受け取った `kindle2notion.apk` をスマホで開く
2. 「この提供元のアプリを許可」を求められたらオンにする（APK を開いたアプリ — Claude アプリやファイルアプリ — ごとに 1 回）
3. Play プロテクトの警告が出たら「詳細」→「インストールする」（自分用に作ったアプリで、ストアの開発者登録がないため出ます）
4. 「ハイライト」アプリを開き、ふだん Chrome で開いている **Vercel の URL**（例: `https://xxxx.vercel.app`）を入力して「保存して開く」
5. 開いた画面の下にある **「接続設定」** に、Render の URL と Basic 認証を保存する
   - アプリは Chrome とは別に保存するので、Chrome で設定済みでもアプリで 1 回必要です
   - アプリの画面は Vercel と同じ URL で動くため、Render の `CORS_ALLOWED_ORIGINS` は今のままで使えます
6. ウィジェットを置く: ホーム画面の何もないところを長押し →「ウィジェット」→「ハイライト」→「Kindle同期・手動追加」をドラッグ

### 使い方

同期・共有の流れは下の PWA 版と同じです（[Kindle の同期](#kindle-の同期kindle同期) ／ [共有から追加](#紙の本などのハイライト追加共有から)）。違いは次の 3 点です。

- 「Kindle同期」はウィジェットからも押せます
- 共有先の名前は「ハイライトに追加」です
- 起動待ちの間は、アプリが画面の消灯を止めます（Web の Wake Lock の代わり）

### 更新と作り直し（開発者向け）

- **画面の変更**（`frontend/`）は Vercel にデプロイされれば、アプリを開き直すだけで反映されます。APK の入れ直しは不要です
- **アプリ本体の変更**（`android/`）だけ、APK を作り直して入れ直します: `android/build.sh`（手順と必要なツールはスクリプト冒頭のコメント参照）
- **署名鍵はリポジトリに入れません**（公開リポジトリのため）。Android は**同じ鍵で署名した APK しか上書きインストールできない**ので、鍵が変わったビルドを入れるときは先に古いアプリをアンインストールしてください（Vercel の URL と接続設定は入れ直しになります）。同じ鍵で更新し続けたい場合は、鍵を保管して `K2N_KEYSTORE` / `K2N_KEYSTORE_PASS` で渡します

### 将来の注意: 開発者の本人確認

Google は、確認済みの開発者以外のアプリを認定済み Android 端末にインストールさせない仕組みを、2026 年 9 月 30 日からブラジル・インドネシア・シンガポール・タイで始めており、2027 年に全世界へ広げる予定です（日付は未発表）。日本は 2026 年 11 月時点では対象外なので、この APK は今のまま入れられます。対象になった後は、新しく入れ直すときに開発者登録などが必要になる可能性があります。その場合は PWA 版を使えば、同じ機能のうちウィジェット以外はそのまま使えます。

- [Understanding Android developer verification（Google 公式ヘルプ）](https://support.google.com/android-developer-console/answer/16561738?hl=en)

## PWA 版

Vercel で配信しているスマホ向け UI を、Android の Chrome から**アプリとしてインストール**できます。APK のビルドは不要です。

### 前提

- Vercel 版の接続設定が済んでいること（[`DEPLOY_TURSO_RENDER_VERCEL.md`](DEPLOY_TURSO_RENDER_VERCEL.md) の STEP 4）
- Android の **Chrome** を使うこと。インストールには HTTPS が必要なので、Vercel（または Render）の `https://` の URL から入れてください（LAN の `http://192.168...` ではインストールできません）

### インストール手順（1 回だけ）

1. Android の Chrome で Vercel の URL（例: `https://xxxx.vercel.app`）を開く
2. 開始画面の **「スマホにアプリとしてインストール」** を押す
   - ボタンが出ない場合は、Chrome のメニュー（⋮）→ **「アプリをインストール」** または **「ホーム画面に追加」**
3. ホーム画面に「ハイライト」アイコンができたら完了
   - 接続設定（バックエンド URL・Basic 認証）は Chrome で保存したものが通常そのまま引き継がれます。アプリを開いて「バックエンドに接続できました。」と出なければ、アプリ内の「接続設定」で一度保存してください
4. （おすすめ）アイコンを長押し →「Kindle同期」をホーム画面へドラッグ。置いた「Kindle同期」が 1 タップで同期を始めるボタンになります

### Kindle の同期（「Kindle同期」）

1. 「Kindle同期」をタップすると、アプリが開いて「バックエンドの準備ができ次第、自動で同期を開始します」と表示されます
2. Render の無料プランはスリープしていると起動に 1〜3 分（長いと数分）かかります。**開始するまではアプリを開いたままにしてください**（待っている間は画面が消えないようにしています）
3. 同期が始まったら、アプリを閉じても処理はサーバー側で続きます。開き直すと進捗を再表示します
4. 2 段階認証を求められたときだけ、5 分以内にアプリでコードを入力してください（Turso にセッションが保存されていれば、通常は求められません）

すでに同期が動いているときに押しても、二重には起動せず、その同期の進捗を表示します。「自動開始をやめる」で待機を取り消せます。

### 紙の本などのハイライト追加（「共有」から）

1. Google レンズで本のページを撮影して文章を選ぶ、または PDF リーダーやブラウザで文章を選ぶ
2. **「共有」→「ハイライト」**（APK 版は「ハイライトに追加」）を選ぶ
3. 手動追加画面が、文章を入力した状態で開きます
   - OCR や PDF の行の折り返しは 1 行につなげます（日本語は空白なしで連結）。複数のハイライトに分けたいときは改行で区切ってください
   - 共有に含まれる URL は取り除きます
4. 本のタイトルを決める。直前に追加した本なら **「前回の本を使う」** を 1 タップ（タイトルは自動では入りません。別の本に入れてしまうのを防ぐため）
5. 「内容を確認」→「この内容で追加する」

### 仕組みと制約

- **PWA にはホーム画面ウィジェットを作れません**（Android は Web アプリのウィジェットに対応していない）。ウィジェットが必要なら APK 版を使ってください
- **起動待ちはアプリを表示している間だけ進みます**（APK 版も同じ）。Android はバックグラウンドのアプリを止めるため、開始前に別のアプリへ切り替えると待機は一時停止し、戻ると続きから再開します。開始前にアプリを完全に閉じた（最近使ったアプリの一覧から消した）場合は、もう一度「Kindle同期」をタップしてください。サーバーが起きている（直近 15 分以内に使った）ときは即座に開始します
- Service Worker は**ネットワーク優先**です。キャッシュはオフライン時に画面を開くためだけに使い、API（Render への通信）には一切関与しません。そのため、デプロイした修正はアプリを開き直せば反映されます
- アイコンやアプリ名（`frontend/manifest.webmanifest`）を変えた場合、インストール済みアプリへの反映は Chrome の定期チェック任せで、数日かかることがあります。急ぐ場合はアンインストールして入れ直してください

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| （APK）「アプリはインストールされていません」「パッケージが競合しています」 | 署名鍵の違うビルドで上書きしようとしています。古い「ハイライト」をアンインストールしてから入れてください |
| （APK）「画面を開けませんでした」 | 通信できるか確認し「再読み込み」。URL を間違えた場合は「接続先を変更」 |
| （APK）ウィジェット一覧に出てこない | インストール直後はホームアプリの一覧更新が遅れることがあります。ホームアプリを再起動するか、少し待ってください |
| （PWA）「スマホにアプリとしてインストール」が出ない | すでにインストール済みか、Chrome が条件を満たすと判断する前です。Chrome のメニュー →「アプリをインストール」/「ホーム画面に追加」を使ってください |
| （PWA）共有メニューに「ハイライト」が出ない | Chrome からインストールしたアプリでのみ表示されます。一度アンインストールして、上の手順で入れ直してください |
| 長押ししてもショートカットが出ない | 使っているホームアプリが長押しショートカットに対応していない可能性があります。アプリ内のボタン（APK 版はウィジェット）で同じ操作ができます |
| 「接続設定でバックエンド URL を保存してください」と出る | 画面下の「接続設定」に Render の URL と Basic 認証を保存してください |
| CORS のエラーが出る | Render の `CORS_ALLOWED_ORIGINS` に Vercel の URL（`https://` から、末尾スラッシュなし）を設定してください |
| 修正が反映されない | アプリを完全に閉じて開き直してください（最近使ったアプリの一覧から消す） |
